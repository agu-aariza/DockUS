# frontend/public/

Assets estáticos servidos directamente por Vite.

## Archivos

| Archivo/Carpeta | Descripción |
|-----------------|-------------|
| [`logos/`](./logos/) | Logotipos de la aplicación (`Logo01.png`, `Logo02.png`). |
| `index.html` | Plantilla HTML principal (punto de entrada de la SPA). |

## Notas

- Los archivos de esta carpeta se copian tal cual al directorio de build.
- `index.html` incluye el script de entrada de Vite y las referencias a fuentes/favicon.
