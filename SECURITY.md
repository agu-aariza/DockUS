# Security Policy

## Alcance

Este repositorio procesa código no confiable, credenciales de proveedores LLM, informes académicos y datos de usuarios. Los límites técnicos y el modelo operativo están en [`docs/security.md`](docs/security.md).

## Reportar vulnerabilidades

No publiques detalles explotables en issues públicos ni en pull requests. Comunica el problema por un canal privado a los mantenedores del proyecto e incluye versión o commit, impacto, pasos de reproducción y una propuesta de mitigación si la tienes.

Antes de publicar el proyecto, sustituye esta instrucción por un canal de contacto privado concreto y monitorizado.

Prioriza la protección inmediata de secretos, datos personales, cuentas y hosts Docker antes de preparar una corrección pública.
