## 📋 Descripción

**DockUS** es un ecosistema profesional diseñado para la gestión de entornos de desarrollo reproducibles y la evaluación automatizada de proyectos académicos. 

---

## 🛠️ Estrategia de Desarrollo (DevOps)

DockUS sigue los estándares de ingeniería de software más exigentes:

### 1. Convención de Commits
Se utiliza **Conventional Commits** para garantizar un historial trazable y legible.
- `feat`: Nuevas funcionalidades.
- `fix`: Corrección de errores.
- `ci`: Cambios en pipelines.
- `docs`: Documentación.
- `chore`: Tareas de mantenimiento o configuración.

### 2. Ciclo de Vida CI/CD
- **Integración Continua (CI):** Ejecución de linters, tests y verificación de builds en cada PR.
- **Despliegue Continuo (CD):** Publicación automática en **GitHub Container Registry (GHCR)**.
- **Git Flow:** Estrategia de ramas `main`, `develop` y `feature/*` para un desarrollo paralelo seguro.
